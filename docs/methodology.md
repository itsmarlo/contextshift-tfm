# Scientific methodology

## Question and hypotheses

ContextShift asks how the labeled context affects a pretrained tabular foundation model. The five study families are size, quality, relevance, class imbalance, and concept drift. Quality has four independent interventions: missing values, label flips, numerical noise, and outliers. We hypothesize that context changes can alter predictions, not that any intervention always helps or hurts.

## Synthetic process

`experiments/generate_dataset.py` defines eight numeric features: age, annual premium, prior claims, policy duration, insured amount, risk tier, geographic risk indicator, and late payment count. Population B has higher premiums, longer duration, and more prior claims on average. Claims are sampled from a Bernoulli distribution with probability `sigmoid(logit)`. Period A's logit is:

`-3.1 + .35*priorClaims + .32*(risk-1) + .33*geo + .23*payment + .0002*(premium-1200) + .0017*(age-45)^2 - .048*duration + .16*populationB`

Period B adds `.55 - .55*priorClaims + .14*duration`, a controlled relationship change. Feature distributions also differ. This is a teaching construct; it does not describe real insurance customers or establish causal relationships.

## Splitting and controls

Training candidates and held-out tests use separate RNG streams (`seed`, `seed+10000`). Recent Period B candidates and tests use `seed+20000` and `seed+30000`. Context selection, noise, and label flips never inspect held-out labels. Within each study, each model sees the same context and test features. Size contexts are nested for a fixed seed. Quality interventions modify only context rows. Relevance uses a fixed Population B test subset. Drift uses an unchanged Period B test set. Context size is 100 except for the size study. Full mode uses seeds 7, 17, and 27; quick mode uses seed 7.

Missing values are represented as NaN in the model inputs. TabPFN, SAP-RPT-OSS, XGBoost, and CatBoost perform their own missing-value handling. No imputer is fitted on held-out data. All four models receive the same numeric feature values, with risk tier encoded as an integer. The RPT adapter supplies the corresponding feature names and names the target `claim` for its semantic tokenizer. XGBoost and CatBoost each fit a new 100-tree, depth-3 model per run with learning rate 0.06; their tree structures and optimization differ, so equal tree counts do not imply equal model capacity. These are fixed configurations, not tuned model searches. TabPFN and RPT receive context during their `.fit()` / `.predict_proba()` protocols with pretrained weights; exported fit timing is an API call duration, not a comparable amount of task-specific training.

## Metrics and export

Predictions use a 0.5 decision threshold. Accuracy, precision, recall, F1, ROC AUC, PR AUC, log loss, Brier score, predicted positive share, and the 2×2 confusion matrix are computed on held-out truth. Zero division yields zero precision or recall. ROC and PR AUC are `null` if only one test class is present. Each run records model and dataset versions, seed, configuration, the first ten individual prediction probabilities and five calibration bins computed over the full test set, timing, UTC timestamp, hardware, and a ten-row context preview. The JSON bundle has `schema_version: "1.0"`. No interpolation is used for unrun combinations.

## Browser simulator

The Playground demonstrates the input structure described by Hollmann et al.: labeled context rows and an unlabeled query produce a prediction without changing pretrained weights. Its browser calculation is a separate, explicit similarity-weighted average, not the TabPFN or SAP-RPT-OSS algorithm. Quick actions, context size, and direct cell edits update immediately. The other sliders change only the shown context rows after Apply; the query stays fixed. Label corruption flips the requested share rounded to whole rows, premium noise varies premiums by up to the shown percentage, premium outliers multiply selected premiums by five, missing premium blanks selected cells, duration shift adds the shown number of years, risk-tier mix moves selected tiers toward 1 or 3, and positive share sets the shown Claim-label proportion. The add-example action creates a nearby hypothetical labeled row; it does not reveal or reuse the query’s hidden label. The influence shares are normalized weights from this educational calculation; they are not TabPFN attention weights or causal feature attributions. The original ten rows stay fixed as the comparison reference.

The **My CSV** workspace applies a similarity-weighted average to a local file. It accepts up to 500 rows, numeric features, blank feature values, and a numeric target with at least two different known values. Targets with only 0/1 known values are shown as binary classification probabilities; other numeric targets are shown as regression estimates. An empty target cell or `[PREDICT]` marks a row to predict. Every marked row is excluded from context. A known row may also be selected as a held-out query, with its actual target shown only after calculating the prediction. Feature scales come from the original known training rows and stay fixed while context size or values change. Outputs are not calibrated risk estimates or measured foundation-model results. User CSV bytes stay in browser memory; the sample is fetched from the public site.

The workspace reserves every fifth known row for a fixed validation set and uses the remaining known rows to build contexts. The selected query row is excluded from its own prediction. Each validation query is likewise excluded from its context. Binary targets are scored by accuracy at a 0.5 threshold; numeric targets use mean absolute error. The clean reference uses the same requested context size. Scores are descriptive for the uploaded sample and can be noisy with very few held-out rows. Repeatedly tuning to this validation set can overfit it; use a separate test set for a real model comparison.

The context controls reproduce the study families as a browser teaching rule. Size changes the count of selected rows. Missing features blank a requested proportion of nonblank numeric context cells. Target corruption flips selected 0/1 targets or perturbs selected numeric targets. Feature noise adds deterministic scale-relative changes to context values. Outliers add five feature ranges to one numeric feature in selected rows. Group relevance selects a requested share whose group column matches the query row; class balance selects a requested positive-label share; recent-data share selects a requested share with the chosen period value. Feasibility depends on how many rows exist in each category, so the displayed actual share may differ from the requested share. These changes affect only context rows, never validation truth or the uploaded file.

## Limits

The generated data is small and designed for explanation. The conclusions cannot be generalized to live insurance portfolios or used to rank models universally. There is one synthetic generator and one held-out test set per study; three seeds vary context sampling, not the underlying dataset. Clean-test prevalence is 9.7%, so accuracy near 90.3% can mean no positive claims are detected at the 0.5 threshold. ROC AUC, PR AUC, log loss, F1, and recall should be interpreted together. Population similarity and recent context are not guaranteed to improve predictions. Covariate shift changes the feature distribution; prior shift changes class prevalence; concept drift changes the feature–outcome relationship. These can co-occur in the generator. Model weights are downloaded separately and are not committed.

## Reproduce

Use Python 3.11 or 3.12. Create a virtual environment, install `experiments/requirements.txt`, then run `python -m experiments.run_experiments --mode quick` or `--mode full` from the repository root. On the validation Mac, set `OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1` for the command to avoid an OpenMP initialization crash. The first TabPFN run downloads pretrained weights. The bundled full grid contains 132 matched configurations for each of TabPFN 2.2.1, XGBoost 2.1.3, CatBoost 1.2.10, and SAP-RPT-OSS across seeds 7, 17, and 27. The RPT adapter uses SAP's research checkpoint with a 2,048-row maximum context and one bag. Its model version field records the checkpoint and inference settings; its runs were measured on CPU. SAP's commercial RPT Playground model is a different checkpoint. Rebuild the frontend after export. The browser simulator is independent of this pipeline.
